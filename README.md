# Trading bot (paper)

Runs automatically on GitHub every weekday at 15:05 UTC (10:05 New York in winter): downloads prices,
checks risk, rebalances on the first trading day of each month, and writes Obsidian notes.

Start with **00 - Bot Dashboard.md**. Settings: **02 - Risk Limits.md**. Manual run: Actions tab →
"Trading bot daily run" → Run workflow.
