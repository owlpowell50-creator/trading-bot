## One idea worth testing

**Walk-forward test of the T-bill hurdle buffer** (the follow-up proposed in [[Desk Note 2026-11-25]]).
- **The rule being tested:** an asset already held stays in while its score is above *T-bills − x*. A new asset gets in only if it beats *T-bills + x*.
- **How I tested it:** I chose x using only **1997–2011**, then judged it on **2012–2026**, data the choice never saw.
- **Tools and settings:** the repo's own `bot/backtest.py`, run in a scratch copy, with live settings (10 bp costs, 10% no-trade band). No live files or rules were touched.
- **Sanity check:** with x = 0 the code reproduces live CORE exactly (2012– CAGR 8.16%, Sharpe 0.817).

| Buffer x | 1997–2011 CAGR / Sharpe (choose here) | 2012–2026 CAGR / Sharpe (judge here) | 2012– max DD | 2012– turnover (total) |
|---|---|---|---|---|
| 0 (live) | 11.60% / 1.074 | 8.16% / 0.817 | -17.6% | 37.8 |
| 0.5% | 11.49% / 1.063 | 8.23% / 0.820 | -19.0% | 36.2 |
| 1% | 12.04% / 1.109 | 8.33% / 0.826 | -19.0% | 34.8 |
| 1.5% | 12.04% / 1.109 | 8.14% / 0.815 | -17.8% | 34.9 |
| **2% (best in 1997–2011)** | **12.03% / 1.110** | **8.25% / 0.835** | **-17.8%** | **33.8** |
| 3% | 11.82% / 1.089 | 7.63% / 0.782 | -17.7% | 33.3 |
| 4% | 11.62% / 1.072 | 8.12% / 0.826 | -17.7% | 30.3 |

- **Result:** the setting picked on the early data (2%) beat live rules on the unseen data, but only by **+0.09%/yr** CAGR and +0.02 Sharpe. Turnover was **11% lower**, and the drawdown was 0.2 points worse.
- **Luck test:** a block bootstrap (`bt.block_bootstrap_beat`) puts the chance that 2% really beats live rules at **59%**. The 90% range of the yearly difference runs from **-0.45% to +0.67%**, so the result cannot be told apart from luck.
- **Fragile choice:** neighbouring settings are not consistent. 1.5% did slightly *worse* than live after 2012, and 3% was clearly worse.
- **After US tax** (`bt.USTax`, 1997–2026): live 7.36%, buffer 1% **7.60%**, buffer 2% **7.59%**. Turnover per year falls from 2.28 to 2.06. Lower turnover is the most consistent benefit, and it is worth about 0.2%/yr after tax.
- **Verdict:** keep live rules. If the owner wants to explore this further, the honest version is a 1–2% buffer justified by *lower turnover and tax*, not by better returns. It should be judged in a paper shadow run, not switched on.
- **Effect this month:** a 2% buffer would block real estate (score 3.5% against the 4.2% it would need). The 1 Dec move would then be about **commodities 31% and cash 69%**, instead of adding a 36% real-estate position.

Script: a scratch copy only, not committed (`wf_buffer.py`, which subclasses `strategies.Core`).
